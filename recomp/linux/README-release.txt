Densha de GO! FINAL (PC), recompiled - ddg-recomp

This program contains no part of the game. It needs your own copy of Densha de GO! FINAL for the
PC: the cddata folder and an unprotected perfect.exe (the one on the CD is protected by SafeDisc
and cannot be used; a copy patched by DDGModernizer works).

The first start
  A settings window opens: choose the game folder (the one with cddata) and, if it is not in that
  folder, perfect.exe. The program then translates perfect.exe and compiles the result for this
  computer, which takes about one to two minutes (only the first time, and again after an update
  or with another exe). Meanwhile you can set resolution, draw distance, frame rate and the other
  options; Start becomes available when the game is ready.

  The translated and compiled game code is kept in ~/.cache/ddg-recomp (macOS:
  ~/Library/Caches/ddg-recomp). It is made from your perfect.exe: do not share it.

Later starts
  The game starts directly. Hold Shift at start, or start with --settings, to get the settings
  window back; F10 (Y on a gamepad) opens the options menu while playing.

Settings and saves: ~/.local/share/TAITO/DengoFinal/ (macOS: ~/Library/Application Support/TAITO/
DengoFinal/).
